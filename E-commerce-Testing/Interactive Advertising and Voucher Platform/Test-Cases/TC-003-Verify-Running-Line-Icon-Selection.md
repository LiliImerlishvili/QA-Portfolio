# TC-003 — Verify Running Line Icon Selection

## Related Defect

- BR-003

## Objective

Verify that selected running line icons appear in preview and published output.

## Preconditions

- Running line is enabled.
- Icon selection is available.

## Test Steps

1. Open the campaign editor.
2. Open the running line settings.
3. Select a different icon.
4. Save the changes.
5. Review the preview and published output.

## Expected Result

The selected icon is displayed correctly and persists after saving.

## Status

Not Executed
