# TC-001 — Verify Language Persistence

## Related Defect

- BR-001

## Objective

Verify that the selected language persists across navigation and reload.

## Environment

| Field | Value |
|---|---|
| Environment | Staging |
| Device | iMac |
| Operating System | macOS Tahoe 26.3.1 |
| Browser | Google Chrome 146 |
| Reproducibility | 100% |

## Preconditions

- The user has the required access level.

## Test Steps

1. Open the platform.
2. Select a non-default language.
3. Navigate to another main page.
4. Observe the interface language.

## Expected Result

The selected language should persist across navigation and page reloads.

## Status

Not Executed
