# Desktop Testing

This section contains QA documentation for native desktop applications.

## Projects

| Project | Description |
|---|---|
| `Quality Engineering Command Center/` | Desktop application for QA management — includes AI-powered scan analysis, bug reporting, test case management, and script editing functionality |

## Project Structure

Each project folder contains:

```
Project Name/
├── Bug-Reports/       — Defects found during testing
├── Test-Cases/        — Detailed step-by-step test cases
├── Test-Scenarios/    — High-level user journey scenarios
├── Checklists/        — Risk-based validation checklists
└── RTM/               — Requirements Traceability Matrix
```

## Testing Focus Areas

- Desktop UI behavior and native controls
- AI provider configuration and scan accuracy
- Script editor functionality and input handling
- Bug report and test case management workflows
- Permission and role-based access within the application
- Data integrity across import and export operations
