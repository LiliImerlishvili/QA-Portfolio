# TC-006 — Verify Add to Home Screen Instructions Are Shown on iOS

## Related Defect

- BR-006

## Objective

iOS users must receive guidance for adding the web app to the Home Screen.

## Test Type

Positive

## Priority

High

## Environment

| Field | Value |
|---|---|
| Environment | Staging |
| Platform | Mobile web |
| Device | iPhone |
| Browser | Safari (iOS) |

## Preconditions

- The website is opened in Safari on an iOS device.

## Test Steps

1. Open the browser share menu.
2. Select **Add to Home Screen**.
3. Observe the guidance on the website.

## Expected Result

- Clear installation instructions are displayed.
- The user receives confirmation after adding the app.

## Status

Not Executed
