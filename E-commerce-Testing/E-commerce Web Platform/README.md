# E-commerce Web Platform

**Role:** Manual QA Engineer  
**Platform:** Web  
**Period:** Oct 2025 – Present  

## Overview

Large-scale e-commerce web platform with product catalog, filters, favorites, cart and checkout, and multilingual (Georgian / English) content.

## Testing Focus

- Category browsing, filters and product pages
- Registration, login and favorites
- Checkout with valid and invalid data
- Language switching and localization
- Similar products and brand pages
- Mobile layout and comparison with Figma designs

## Testing Types

Functional · Regression · UI/UX · Exploratory
