# CL-003 — Roles, Workspaces and AI Features Checklist

## Roles and Permissions

- [ ] Owner, Admin, Member and Guest see only permitted modules
- [ ] Restricted actions are hidden or disabled
- [ ] Direct URL access to restricted pages is blocked
- [ ] Role changes apply without re-login issues

## Workspace Isolation

- [ ] Projects, invoices and reports are isolated per workspace
- [ ] Switching workspaces refreshes all data
- [ ] Search does not return data from other workspaces

## Cross-Module Synchronization

- [ ] Changes in projects reflect in pipelines, CRM and reports
- [ ] Crew and task updates sync across views
- [ ] Calendars and files are linked to the correct project

## AI-Assisted Workflows

- [ ] AI reply options are generated and editable
- [ ] Attachments are handled correctly in AI flows
- [ ] Batch actions show a preview before applying
- [ ] Duplicate items are not created by repeated actions
