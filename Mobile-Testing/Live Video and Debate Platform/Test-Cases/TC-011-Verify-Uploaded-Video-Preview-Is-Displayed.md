# TC-011 — Verify Selected Video Preview Is Displayed During Upload

## Related Defect

- BR-006

## Objective

Verify that the selected video is shown on screen while it is being uploaded.

## Test Type

Positive

## Priority

High

## Environment

| Field | Value |
|---|---|
| Environment | Staging |
| Platform | iOS |
| Device | iPhone 14 Pro |
| Operating System | iOS 27.0 |
| Application Version | 1.21.0 (1.0.489) |

## Preconditions

- The user is logged in.
- A video exists on the device.

## Test Steps

1. Start the video upload flow.
2. Select a video.

## Expected Result

- The selected video preview is displayed.
- The user can see upload status/progress.

## Status

Not Executed
