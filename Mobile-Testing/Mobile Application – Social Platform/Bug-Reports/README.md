# Mobile Application – Social Platform (Under NDA)

This project represents manual QA activities performed on a cross-platform social networking mobile application.

The application includes real-time chat, notifications, media upload, and user interaction features.

Testing focused on functional correctness, UI/UX consistency, API behavior, and performance stability across multiple devices and OS versions.

Testing Type: Mobile · Functional · UI/UX · API  
Tools: Jira · Postman · Android Studio Emulator
