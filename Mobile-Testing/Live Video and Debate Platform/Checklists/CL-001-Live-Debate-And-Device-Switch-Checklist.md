# CL-001 — Live Debate and Device Switch Checklist

## Live Debate Roles and Permissions

- [ ] Moderator, Yes and No roles are assigned correctly
- [ ] Only the moderator can start the next round
- [ ] Participants can control only their own camera and microphone
- [ ] Viewers cannot speak or control the debate

## Rounds and Timers

- [ ] Round timer starts and ends correctly
- [ ] Countdown starts after **Next Round** is tapped
- [ ] Next round starts when the countdown ends
- [ ] All participants see the same round state

## Leave and Rejoin

- [ ] Participant can leave via **Back** and **Leave**
- [ ] Participant can rejoin the same live debate
- [ ] Force close and reopen on the same device does not show the "Switch Device" modal
- [ ] Role, camera and microphone state are restored after rejoin

## Device Switch (Mobile ↔ Web)

- [ ] "Switch Device" modal appears only when a different device is used
- [ ] Session moves to the new device after confirmation
- [ ] Previous device session ends correctly
- [ ] Live debate does not freeze after the switch
- [ ] Device switch works for every role

## Network Conditions

- [ ] Reconnecting indicator is shown during network loss
- [ ] Automatic reconnect after short network loss
- [ ] Behavior on Wi-Fi ↔ mobile data change
