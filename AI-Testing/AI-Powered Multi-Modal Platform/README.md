# AI-Powered Multi-Modal Platform

**Role:** Manual QA Engineer  
**Platform:** Web  

## Overview

Multi-modal AI platform that combines conversational AI with audio, image and video generation, integrating multiple AI models in prompt-driven user workflows.

## Testing Focus

- Conversational AI and prompt-based workflows
- Audio generation, including multi-speaker mode
- Image generation, editing and text extraction
- Video generation and media processing
- AI content detection features
- Payments, chat upload and browser extension

## Testing Types

Functional · Exploratory · UI/UX · AI Workflow Validation · Prompt-based Testing
