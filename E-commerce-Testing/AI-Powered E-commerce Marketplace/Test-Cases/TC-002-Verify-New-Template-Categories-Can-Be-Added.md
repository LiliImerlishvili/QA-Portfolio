# TC-002 — Verify New Categories Can Be Added From a Template

## Related Defect

- None (additional coverage)

## Objective

Verify the positive template flow.

## Test Type

Positive

## Priority

High

## Environment

| Field | Value |
|---|---|
| Platform | Web |
| Device | iMac |
| Operating System | macOS Tahoe 26.5.2 (25F84) |
| Browser | Google Chrome 153 |

## Preconditions

- The user has a store with no categories.

## Test Steps

1. Click **Add from Template**.
2. Select several categories.
3. Click **Add Categories**.

## Expected Result

- A success message shows the correct number.
- The categories appear in the store category list.

## Status

Not Executed
