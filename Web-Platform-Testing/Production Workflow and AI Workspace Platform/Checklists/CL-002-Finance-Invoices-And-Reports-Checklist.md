# CL-002 — Finance, Invoices and Reports Checklist

## Invoices

- [ ] Invoice amounts are rounded consistently (e.g., 1234.56 → $1,235)
- [ ] Status changes (Draft, Sent, Paid, Overdue) are saved
- [ ] Overdue card counts Overdue and past-due Sent invoices
- [ ] Outstanding total is correct

## Financial Overview

- [ ] Payment Status follows invoice statuses (all / some / none paid)
- [ ] Project without invoices keeps the manual status
- [ ] Working Actuals reflects the attached cost report
- [ ] Values match Budgets & Invoices and project details

## Reports and Dashboard

- [ ] Reports totals match the Invoices summary
- [ ] Dashboard overdue list is correct
- [ ] Data persists after refresh and re-login

## Bidding and Budget

- [ ] Bid total and Budget total are clearly labeled
- [ ] Comparison between Bid and Budget is possible
