# Heritage Hair Styling Brand Website

**Role:** Manual QA Engineer  
**Platform:** Web  
**Period:** Oct 2025  

## Overview

Brand website with e-commerce functionality for a heritage hair styling company, focused on UI/UX consistency, responsive behavior, SEO readiness and analytics accuracy.

## Testing Focus

- Modular layouts, sliders, dropdowns and interactive UI elements
- Responsive and cross-browser behavior on desktop, tablet and mobile
- SEO fundamentals: metadata, schema markup, search
- CTAs, redirections and social sharing
- GA4 / GTM tracking and cookie consent

Functional · Regression · UI/UX · SEO Validation
