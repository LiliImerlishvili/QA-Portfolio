## Heritage Hair Styling Brand Website (NDA Project)

**Role:** Manual QA Engineer  
**Period:** Oct 2025  

### Project Overview
Manual QA testing for a brand-focused website of a heritage hair styling company.  
The project focuses on UI/UX consistency, responsive behavior, SEO readiness, analytics accuracy, and user engagement flows.

### QA Responsibilities
- Validate modular layouts, sliders, dropdowns, and interactive UI elements
- Perform responsive and cross-browser testing across desktop, tablet, and mobile
- Verify SEO fundamentals including metadata, schema markup, and search behavior
- Test CTAs, redirections, and social sharing flows
- Validate GA4 and GTM tracking events and cookie consent compliance
- Report defects and support retesting cycles before release

### Testing Type
Functional · Regression · UI/UX · SEO Validation

### Tools Used
Jira · Chrome DevTools · Postman · GA4 · GTM
