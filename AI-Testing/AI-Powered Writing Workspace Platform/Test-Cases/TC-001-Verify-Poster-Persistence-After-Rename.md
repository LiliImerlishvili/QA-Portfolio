# TC-001 — Verify Poster Persistence After Rename

## Related Defect

- BR-001

## Objective

Verify that renaming a project preserves its poster.

## Environment

| Field | Value |
|---|---|
| Environment | Staging |
| Device | iMac |
| Operating System | macOS Tahoe 26.4.1 |
| Browser | Google Chrome 147 |
| Reproducibility | 100% |

## Test Steps

1. Open the Library page.
2. Select a project that already has a poster.
3. Choose Rename.
4. Change the project name.
5. Save the change.

## Expected Result

Renaming should update only the project name and preserve the existing poster.

Not Executed
