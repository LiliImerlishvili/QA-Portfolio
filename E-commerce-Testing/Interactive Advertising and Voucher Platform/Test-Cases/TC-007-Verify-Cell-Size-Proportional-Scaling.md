# TC-007 — Verify Cell-Size-Based Proportional Scaling

## Related Defect

- BR-007

## Objective

Verify that dependent desktop elements scale proportionally with cell size.

## Preconditions

- Grid settings are available.
- A cube contains promotional labels and counters.

## Test Steps

1. Open grid settings.
2. Increase the desktop cell size.
3. Observe related elements.
4. Decrease the desktop cell size.
5. Compare proportions.

## Expected Result

Labels, counters, countdown, running line, and company name scale consistently.

## Status

Not Executed
