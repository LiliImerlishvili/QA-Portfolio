# Healthcare Staffing Mobile Application

NDA-protected Android healthcare staffing application connecting qualified healthcare professionals with elderly care facilities. Role: **Android QA (Manual)**.

The platform allows professionals to discover flexible shifts, set salary expectations and receive job offers, while healthcare facilities can publish vacancies and manage staffing requests.

## Challenge

Ensuring reliable shift discovery, accurate job information and consistent application workflows. Functional issues could cause scheduling conflicts, incorrect shift details and poor user experiences.

## Approach

- Performed manual functional testing on Android
- Tested registration, login and profile management
- Validated shift discovery and selection workflows
- Verified job preferences and salary expectations
- Tested job offers and user interactions
- Checked form validation and error handling
- Performed positive, negative, exploratory and regression testing
- Documented defects with reproduction steps and evidence
- Retested fixes and verified expected behavior

## Key Testing Areas

- Authentication and user profiles
- Shift discovery and availability
- Job preferences and salary expectations
- Shift selection and job offers
- Form validation and error handling
- Navigation, usability and session management

## Impact

- Improved reliability of critical application workflows
- Identified defects affecting shift discovery and interactions
- Supported application stability through regression testing
- Contributed to a more consistent mobile user experience
