# Service Marketplace Platform

**Role:** Manual QA Engineer  
**Platform:** Web  

## Overview

Service marketplace connecting customers with gardening and outdoor-care professionals, with professional verification, service requests and notification integrations.

## Testing Focus

- Registration, phone validation and OTP security
- Professional verification and Slack notifications
- Password reset and registration session recovery
- Service requests, scheduling and offers
- Work-in-progress reminders and service confirmation (SMS, in-app)
