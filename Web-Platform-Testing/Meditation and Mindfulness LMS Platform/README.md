**Role:** Manual QA Engineer  
**Platform:** Web

## Overview

Meditation and mindfulness learning management system that combines structured online courses with e-commerce, multilingual content and privacy-compliant user flows.

## Testing Focus

- WooCommerce checkout with multiple payment methods
- Multilingual course content and system messages
- GDPR, cookie consent and secure forms
- SEO metadata, GA4 events and newsletter opt-in
