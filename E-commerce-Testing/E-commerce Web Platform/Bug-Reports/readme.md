## E-commerce Web Platform (NDA Commercial Website)

**Role:** Manual QA Engineer  
**Period:** Oct 2025 – Present  

### Project Overview
Manual QA testing for a large-scale e-commerce web platform, focusing on core purchase flows, multilingual support, and regression stability before major releases.

### Responsibilities & Achievements
- Performed full-cycle manual testing of product listing, filtering, cart, and checkout flows
- Validated multilingual behavior and data consistency across localized versions
- Identified functional and UI/UX issues impacting user conversion
- Executed regression testing to ensure stable releases after feature updates
- Reported, tracked, and verified fixes in Jira in close collaboration with developers
- Supported release readiness by validating critical user journeys end to end

### Testing Type
Functional · Regression · UI/UX · Exploratory

### Tools Used
Jira · Chrome DevTools · Postman · SQL · TestRail
